zalgollo

Glitch text for agents and apps. The web studio lives at bit-trading-company.com/zalgollo.

MCP

claude mcp add --transport http zalgollo /mcp
ToolWhat it does
zalgo_textGlitch text: presets, per-zone counts, silhouettes (shape), styled alphabets, seeds.
style_textUnicode alphabets: bold, fraktur, script, circled, fullwidth, upside-down…
clean_textStrip zalgo marks and invisible characters, fold styled letters.
inspect_textX-ray: every code point with its Unicode name.
zalgo_optionsList presets, mark sets, styles and shapes.

REST

curl "/api/zalgo?text=hello&preset=crown"
curl "/api/zalgo?text=hello&above=8&below=3&seed=42&format=json"
curl "/api/zalgo?text=mountain&shape=mountain&shapeHeight=20"
curl "/api/style?text=hello&style=fraktur"
curl "/api/clean?text=h%CC%B7%CD%9Di"
curl "/api/inspect?text=h%CC%B7i"
curl "/api/options"
/api/zalgo paramValues
textRequired, up to 1000 characters
presetwhisper, classic, he-comes, crown, drip, strike, halo, bridges, letters, thai, monolith, static, native, chaos
above middle below enclose bridge otherAverage marks per letter in each zone (0–100)
intensity density jitterScale counts · share of letters (0–1) · variation (0–1)
setsComma list: classic (default), supplement, extended, symbols, half, cyrillic, letters, thai, indic, semitic, tibetan, musical, halos, enclosing, all
shape shapeHeight shapeZoneflat, wave, ramp, fade, mountain, valley, dome, spikes, heartbeat, skyline, noise, walk, equalizer · peak height · both/above/below
stylebold, italic, script, fraktur, double-struck, sans, monospace, fullwidth, small-caps, circled, squared, upside-down, …
scrambleComma list of Unicode blocks to swap letters for (Runic, Braille Patterns, …)
seed · formatReproducible output · text (default) or json
