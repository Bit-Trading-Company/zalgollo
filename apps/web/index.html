How glitch text works

One letter, many code points

Unicode lets any letter carry an unlimited number of combining marks — accents that don't take up space of their own. Fonts place each new mark further out, so piling on dozens builds towers that spill out of the line, over the text above and below, and sometimes out of the app itself. That's zalgo.

Text as an object

Zalgollo keeps your text as a list of letters, each with its own stack of marks sorted into zones. Edit the plain text and the marks stay put; paint, sketch or pick individual marks; the studio compiles it all back into a single string you can paste anywhere.

Where does it work?

Anywhere that accepts Unicode: Discord, X/Twitter, Instagram bios, TikTok, Reddit, Steam names, code comments. Some apps trim tall stacks or cap character counts — the stats bar shows code points and UTF-16 length so you can stay under limits.

Questions

Is zalgo text safe to paste?

Yes — it is ordinary Unicode. Extremely tall stacks (hundreds of marks per letter) can make some apps slow to render; the stats bar shows the tallest stack so you can keep it reasonable.

Why do some marks show as boxes?

Not every font has every mark. The Marks tab can test your device and hide marks it can't draw. "Everything" and "Static" presets use them on purpose.

How do I remove zalgo from text?

Paste it into the X-ray tab and press Clean. It strips combining marks, invisible characters and folds styled alphabets back to plain letters.

What is invisible ink?

A message hidden in Unicode variation selectors or tag characters — invisible when displayed, but still in the text. X-ray reveals and removes it. Handy for watermarks and puzzles; be considerate about where you use it.
